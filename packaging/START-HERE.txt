TOS NEO Companion - start here
==============================

Full guide: https://github.com/MotazMSAG/tos-neo-companion#quick-start-for-players

Before the first start
  1. Windows display scaling must be 100%:
     Settings > System > Display > Scale = 100%.
  2. The game: windowed mode, maximized, on a 1920x1080 monitor, English client.
  Nothing else to set up: the game folder and your time zone are found by themselves.

First start
  3. Start the game first (this helps the companion find it), then double-click
     Companion.App.exe. Windows may say "Windows protected your PC": click "More info",
     then "Run anyway". Click Yes on the admin prompt.
     If it cannot find the game, a small window asks you to start the game and press
     "Try again", or to "Choose folder..." (the folder with TOS.exe). It remembers it.
  4. A tray icon appears near the clock. Right-click it > Advanced > Trust this build...
     Nothing runs before that.
  5. Left-click the tray icon: the window opens on the Today checklist. It only reads the
     game's log and never clicks: it is ready.

Crafting automation (optional)
  6. Right-click the tray icon > Advanced > Automation > Crafting (turn it on).
  7. With the game running, press "Scan all recipes" in the companion's Craft tab (5-20 minutes).

Stop everything: Ctrl+Alt+Pause, or tray > Stop now.
Change the game folder later: tray > Advanced > Game folder..., then restart the companion.
Uninstall: tray > Exit, delete this folder, and delete C:\ProgramData\TOS-companion.
