# Test images (tests-owned copies)

Byte-identical copies of game captures from `proofs\out`, read by the image tests through the path helpers
`TestData.Image` (Companion.Vision.Tests), `Support.Image` (Companion.Perception.Tests) and
`RecipeListImageTests.Capture` (Companion.Features.Tests). Proof runs rewrite `proofs\out`; these copies never change,
so the tests always see the captures their expected values were measured on. Never overwrite a file here: add a new
file (and a row below) for a new capture.

All captures: game client 1920x1009 at offset (8,31) in a 1936x1048 window, game not in the foreground. Half scale =
960x504 PNG of the whole client (`SourceLayout.ClientHalf`); full scale = 1920x1009 (`SourceLayout.ClientFull`).

(the `stock-count-dark` font from the clean count images of `stock_*_full.png` tiles); `BuiltInFontTests.MasksMatchTheCaptures`
re-cuts every glyph from these copies, `MakeTabFullCaptureTests` reads every value of every full-scale Make capture and
`StockGridCaptureTests` every tile of every Stock capture against the ground truth listed here. The Stock templates of the
inventory feature (`features\Companion.Feature.Inventory\data`) are cut from these copies too (`StockTemplateTests`).
